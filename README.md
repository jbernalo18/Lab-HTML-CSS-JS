# Laboratorio HTML, CSS y JavaScript

Ejercicio práctico para aprender a conectar **HTML, CSS y JavaScript**, trabajando con elementos del DOM e interacciones mediante eventos.

## Tecnologías

* HTML5
* CSS3
* JavaScript

##  Conceptos practicados

* Estructura básica de HTML.
* Uso de `id` y `class`.
* Selectores CSS.
* Manipulación del DOM con `getElementById()`.
* Modificación de contenido con `innerHTML`.
* Modificación de estilos con JavaScript.
* Eventos `click` con `addEventListener()`.
* Funciones flecha.


Ejercicio realizado como parte de mi formación en desarrollo web.
